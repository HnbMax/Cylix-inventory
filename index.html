Connecter l'inventaire à une base partagée

Cette application a besoin d'une base de données gratuite (Firebase) pour que tous vos collègues voient les mêmes données. À faire une seule fois :

1. Allez sur console.firebase.google.com, connectez-vous avec un compte Google, cliquez sur "Ajouter un projet".
2. Dans le projet, ouvrez "Realtime Database" dans le menu de gauche → "Créer une base de données" → démarrez en mode test (on verrouillera juste après).
3. Ouvrez "Authentication" dans le menu de gauche → "Get started" → onglet "Sign-in method" → activez "Email/Password".
4. Toujours dans Authentication, onglet "Users" → "Add user" → créez un compte (email + mot de passe) pour vous, puis un par collègue qui doit avoir accès.
5. Retournez dans "Realtime Database" → onglet "Règles", et collez : {"rules": {".read": "auth != null", ".write": "auth != null"}} puis "Publier". Cela empêche tout accès sans identifiants valides.
6. Dans les paramètres du projet (⚙️) → "Général" → "Vos applications" → icône Web (</>) → enregistrez une application, copiez l'objet firebaseConfig et collez-le ci-dessous.
